Authentication

{{if eq .AuthMode "open"}}

This server runs in open mode and takes no credential. Open mode is permitted only on a loopback address.

{{else}}

Every request needs an API key, as a bearer token:

curl -H "Authorization: Bearer $NANOASR_KEY" \
  -F file=@call.wav -F model=gigaam-v3-ctc-punct-ru \
  http://localhost:8080/v1/audio/transcriptions

A browser cannot set a header when it opens a WebSocket, so /v1/realtime also accepts the key as a subprotocol: openai-insecure-api-key.<key>. Any script on the page can read a key the page holds, which is what "insecure" refers to; it is still a real key and is checked like one.

{{end}} {{if .Public}}

{{end}} {{if .RealtimeInfo}}
